# Standalone download

Download [signed-lls-explorer-standalone.zip](signed-lls-explorer-standalone.zip),
unzip it, and open `Signed-LLS-Explorer/index.html` in a browser. No installation,
server, account, or internet connection is needed. The ZIP also includes
editable source, examples, tests, and a builder. Send it to collaborators to
run the same app. Edits last for the page session; copy your results to keep
them. See the [offline guide](../STANDALONE.md).
