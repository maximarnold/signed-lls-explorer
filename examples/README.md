# Paste-ready examples

Paste [lls.txt](lls.txt) into the LLS field and choose **Draw from LLS**.
Paste [vertices.txt](vertices.txt) or [real-vertices.txt](real-vertices.txt) into
**Vertex coordinates** and choose **Draw from coordinates**. Coordinate lists
preserve their supplied positions and order. Use **Undo** to return to the
previous line. The [offline guide](../STANDALONE.md) explains supported input
formats, duals, concatenations, and TikZ export.
